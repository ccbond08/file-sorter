# 文件分类器

一个用 Python 写的文件自动整理工具，按文件类型和修改日期自动分类，支持撤销。

## 功能
- 按类型分类：图片、文档、压缩包、视频
- 按修改日期建子文件夹
- 跳过1小时内修改过的新文件
- 生成整理报告
- 支持一键撤销

## 使用方法
1. 运行 `python file_sorter.py`，输入要整理的文件夹路径
2. 如需撤销，运行 `python undo.py`，输入同一个路径

## 文件说明
- `file_sorter.py`：整理脚本
- `undo.py`：撤销脚本
- `整理报告.txt`：整理后自动生成
- `undo.json`：整理后自动生成，供撤销使用

## 依赖
- Python 3.x
- 无需额外安装第三方库
